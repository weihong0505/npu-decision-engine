### 3.2 重写方式

```

<本机代理端口>              ==> 127.0.0.1:<port>
```

## 4. 遗留与风险

### 4.1 不可逆点

- **旧的 3 个提交哈希已消失**（含 `a553e20`）。若有人此前 clone/fork，其本地副本仍留着旧串 —— GitHub 方无 fork（`forkCount: 0`），影响面为 0。
- GitHub 会保留被强推覆盖的 unreachable commit 一段时间（通常约 90 天可恢复），**但页面/API 已不可见**。
- 搜索引擎与第三方存档（web.archive.org 等）可能收录过 10-16 至 11-14 期间的页面快照；**这部分无法撤回**。危害级别：主机名+用户名，无密钥。

### 4.2 仍需注意

1. **今后提交别再把本机路径/主机名带进 JSON**。`src/bench/harness.py` 的 `write_result` 会自动写 `host` 字段 —— 建议改成只写 `platform.node()` 的哈希或 `"redacted"`，从源头堵住。**这是本次审计发现的真正结构性隐患。**
2. `_audit/`（本次的替换脚本与提交信息）通过 `.git/info/exclude` 排除，**不在仓库里、不会上传**，可随时删除。
